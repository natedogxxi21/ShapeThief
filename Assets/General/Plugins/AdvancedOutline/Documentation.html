1. Overview

The Advanced Outline System is a high-performance, feature-rich screen-space outline solution for Unity. It uses the stencil buffer to render crisp, pixel-perfect outlines around meshes, including static meshes and skinned mesh hierarchies. Smooth normals are stored in a generated copy of each mesh, so hard-edged shapes outline cleanly without altering your original model files.

All data the outline needs (outline meshes and materials) is baked into real project assets with one click. Prefabs and scenes then contain everything required, the component never modifies anything in edit mode, and opening a prefab no longer dirties it. Objects that were never baked still work in Play Mode through an in-memory fallback.

2. Quick Start Setup Guide

Follow these steps to apply outlines to any object in your scene:

  1. Add the Component: Select the GameObject you want to outline. In the Inspector, click Add Component, search for Advanced Outline, and add it.
  2. Shader Assignment: When the component is added it automatically finds the Advanced Outline Mask and Advanced Outline Fill shaders and any existing Material Set in the project.
  3. Configure Visuals: Choose the preferred Outline Mode (e.g., OutlineVisible, OutlineAll), select an Outline Color, and adjust the Outline Width in the Inspector.
  4. Bake: Click Bake Outline Assets at the top of the component. The outline is now visible in the editor and stored permanently. For prefabs, do this in Prefab Mode or with the prefab asset selected (see section 3).

3. Persistent Baking (Prefab-Safe Workflow)

Earlier versions generated meshes and materials in memory every time the component enabled, including in edit mode and Prefab Mode. That wrote temporary objects into the prefab/scene on save. The component now never does this in edit mode. Instead, you bake once and the result is stored as assets.

3.1. What Baking Creates

  • Outline mesh assets (Meshes/<MeshName>_<id>_Outline.asset): a copy of each source mesh with smooth normals in UV4 and, for multi-material meshes, one extra submesh covering the whole mesh. One asset per source mesh, shared by every object that uses it. Your original models are never modified.
  • A Material Set (AdvancedOutlineMaterialSet.asset plus Materials/*.mat): five shared materials, one per ZTest variant. They are never modified at runtime; colour, width and dash settings are per-object and written through property blocks.
  • References on the renderers: each baked MeshFilter/SkinnedMeshRenderer points at its outline mesh and each renderer's material list ends with the mask and fill materials. A record of the original meshes is kept on the component so the bake can be undone.

Default location: Assets/AdvancedOutline/Generated/. To use another location, create a Material Set there (Create → Advanced Outline → Material Set) and assign it; the Meshes and Materials folders are created next to it.

3.2. Baking a Prefab

  1. Open the prefab in Prefab Mode (or select the prefab asset in the Project window).
  2. Add Advanced Outline and configure it.
  3. Click Bake Outline Assets, then save the prefab (not needed when baking directly from the Project window).

Baking on a prefab instance in a scene only creates overrides on that instance; the inspector tells you when this is the case.

3.3. Inspector Buttons

  • Bake Outline Assets / Re-Bake: restores the original meshes, then rebuilds all outline data from them. Safe to repeat.
  • Remove Bake: restores the original meshes, removes the outline materials and clears the record. Do this before deleting the component, otherwise the (invisible) outline materials stay on the renderers.
  • Show Material Set: highlights the Material Set asset.

Changing Outline Mode or the Material Set in the inspector swaps the baked materials automatically (one Undo step). Colour, width and effects need no re-bake.

3.4. Menu Items

  • Tools → Advanced Outline → Bake Selected: bakes every Advanced Outline in the selected scene objects and prefab assets.
  • Tools → Advanced Outline → Remove Bake From Selected
  • Tools → Advanced Outline → Strip Outline Materials From Selected: repair tool that removes leftover outline materials from renderers, for example from data written by versions before 1.2. It cannot restore meshes that were lost; reassign those manually.

3.5. When to Re-Bake

The inspector shows a warning (“out of date”) and tells you why. Re-bake after you:

  • change the mesh or material list of an outlined renderer (the outline materials must stay at the end of the list),
  • re-import or edit the source model,
  • add new child renderers that should be outlined.

3.6. Requirements & Notes

  • Reading mesh data may require Read/Write Enabled on the source model's import settings. If a mesh cannot be read, the bake skips it and logs a warning naming the mesh. Baked outline meshes are always readable.
  • Skinned meshes are supported. Smooth normals are not stored for them (custom UVs are not skinned), so they extrude along their regular, animated vertex normals, as before.
  • Renderers that are not mesh or skinned mesh renderers (particles, sprites, lines) are ignored. Renderers owned by a nested Advanced Outline belong to that component.
  • Disabling the component hides the outline but does not remove baked passes from the renderers; use Remove Bake to stop paying for them.

3.7. Un-baked Objects (Runtime Fallback)

If an object is not baked, the outline is generated in memory in Play Mode and builds only, using shared meshes and materials, and removed again when the component is disabled. This keeps objects created at runtime (for example AddComponent<AdvancedOutline>() on a spawned object) working. Nothing is generated in edit mode, in Prefab Mode or on prefab assets. For builds, either bake, or keep the two shader references assigned on the component so they are included in the build.

4. Component Properties Reference

4.1. General Settings

  • Mask Shader: Shader used to mark object geometry in the stencil buffer (used when creating materials).
  • Fill Shader: Shader used to extrude and render the outline color (used when creating materials).
  • Material Set: The persistent materials shared by all outlines. Created automatically on the first bake.
  • Outline Mode:
    • OutlineAll: Renders the outline around the entire mesh.
    • OutlineVisible: Renders the outline only on sections of the mesh visible to the camera.
    • OutlineHidden: Renders the outline only on sections of the mesh hidden behind other objects.
    • OutlineAndSilhouette: Shows outlines on visible sections, and a solid silhouette on occluded sections.
    • SilhouetteOnly: Renders a solid silhouette on occluded sections only.
  • Outline Color: Base outline color.
  • Outline Width: Thickness of the outline stroke (0 to 50).

4.2. Aesthetic Effects (Blendable)

  • Pulse Width: Oscillates the outline width over time.
    • Pulse Speed: Frequency of the oscillation.
    • Pulse Min/Max Width: Bounds of the pulse thickness.
  • Rainbow Color: Smoothly cycles through the HSV color spectrum.
    • Rainbow Speed: Rate of the color cycle.
  • Dashed Pattern: Renders screenspace dashes.
    • Dash Scale: Density/scale of the dash segments.
    • Dash Speed: Velocity and direction of the crawling movement.

4.3. Persistent Outline Data

The panel at the top of the component replaces the old Precompute Outline checkbox. See section 3. Effects (colour, width, pulse, rainbow, dashes) never require re-baking.

5. Script Reference (API)

Access and control the system dynamically through code using the following interface:

Property / Method Type Description
OutlineMode AdvancedOutline.Mode Gets or sets the current active outline depth mode.
OutlineColor Color Gets or sets the base outline color.
OutlineWidth float Gets or sets the outline thickness (0 to 50).
PulseWidth bool Enables or disables outline width pulsing.
RainbowColor bool Enables or disables color cycling.
DashedPattern bool Enables or disables the dashed crawling-ants pattern.
PulseSpeed, PulseMinWidth, PulseMaxWidth float Pulse animation settings.
RainbowSpeed float Rate of the rainbow colour cycle.
DashScale, DashSpeed float Dash density and crawl speed.
MaterialSet AdvancedOutlineMaterialSet The persistent material set used by this component.
IsBaked bool (read-only) True when outline data has been baked into this object's renderers.
RefreshRenderers() void Rebuilds the renderer cache. In Play Mode it also generates live outline data for un-baked renderers. Call this if the hierarchy changes at runtime. Never modifies assets or serialized data in edit mode.
ApplyMaterialsForCurrentMode() void Switches the outlined renderers to the materials matching the current OutlineMode. Called automatically when OutlineMode changes at runtime.

5.1. Editor API (baking from scripts)

The static class AdvancedOutlineBaker (Editor only) exposes the same operations as the inspector, for build scripts and custom tools: Bake(outline), BakeAll(outlines), RemoveBake(outline), ApplyMode(outline) and GetStatus(outline). Components inside prefab assets are baked and the prefab is saved automatically.

5.2. Code Example: Controlling Outlines via Script

To control outline settings dynamically at runtime from other scripts, import the ITISKIRUHERE namespace and modify the component properties as shown in the example below:

using UnityEngine;
using ITISKIRUHERE; // Namespace for the Advanced Outline component

public class OutlineController : MonoBehaviour
{
    [Header("Outline Reference")]
    [SerializeField] private AdvancedOutline _outline;

    private void Start()
    {
        // Automatically find component if not set in Inspector
        if (_outline == null)
        {
            _outline = GetComponent<AdvancedOutline>();
        }
    }

    // Example 1: Activate a pulsing red outline
    public void EnableDangerOutline()
    {
        if (_outline == null) return;

        // Ensure the component is active
        _outline.enabled = true;

        // Configure properties
        _outline.OutlineMode = AdvancedOutline.Mode.OutlineAll;
        _outline.OutlineColor = Color.red;
        _outline.OutlineWidth = 6f;

        // Enable pulsing width animation
        _outline.PulseWidth = true;
        _outline.PulseSpeed = 4f;
        _outline.PulseMinWidth = 2f;
        _outline.PulseMaxWidth = 8f;

        // Disable other conflicting effects
        _outline.RainbowColor = false;
        _outline.DashedPattern = false;
    }

    // Example 2: Activate a crawling dashed cyber outline
    public void EnableCyberOutline()
    {
        if (_outline == null) return;

        _outline.enabled = true;

        // Configure properties
        _outline.OutlineMode = AdvancedOutline.Mode.OutlineVisible;
        _outline.OutlineColor = Color.cyan;
        _outline.OutlineWidth = 4f;

        // Turn off pulsing and turn on dashed crawling pattern
        _outline.PulseWidth = false;
        _outline.RainbowColor = false;
        _outline.DashedPattern = true;
    }

    // Example 3: Completely disable the outline effect
    public void DisableOutline()
    {
        if (_outline != null)
        {
            _outline.enabled = false;
        }
    }
}

6. Shader Details & Rendering Pipeline

The system utilizes two passes for clean composition:

  1. Mask Pass: Draws first, writing a value of 1 to the stencil buffer where the object is rendered. It does not write to the color channel (ColorMask 0).
  2. Fill Pass: Extrudes mesh vertices outward along the precalculated smooth normals. It compares the stencil buffer and discards fragments where the value is 1, ensuring the outline only renders around the outer boundary of the object.

Both shaders use a _ZTest render-state property, which cannot be overridden per renderer, so the Material Set contains one material per variant (mask: Always, LessEqual; fill: Always, LessEqual, Greater). Changing OutlineMode swaps which of them a renderer uses; the assets themselves are never edited.

7. Troubleshooting & FAQ

Q: Why does the outline look jagged on my low-poly mesh?
A: Bake the outline (or re-bake it). The outline mesh stores averaged normals so vertex extrusion stays aligned across sharp polygon seams. Un-baked objects get them generated in Play Mode only, which requires the source mesh to be Read/Write enabled.

Q: Does this component support Skinned Mesh Renderers?
A: Yes. Baking stores an outline copy of the skinned mesh (bone weights, bind poses and blend shapes are preserved) and the renderer's bounds are kept.

Q: Why did my mesh disappear when disabling the script in older versions?
A: In version 1.0, the script destroyed instantiated mesh copies without restoring the original mesh references. This was corrected in 1.1. Version 1.2 goes further: nothing is generated in edit mode, and Remove Bake restores the original meshes from the stored record.

Q: Opening my prefab marks it as modified / my prefab has missing meshes or materials.
A: That was caused by versions before 1.2 swapping meshes and materials for temporary, non-asset objects in edit mode. With 1.2 opening a prefab changes nothing. For prefabs that were already damaged, run Tools → Advanced Outline → Strip Outline Materials From Selected, reassign any missing meshes, then bake again.

Q: The outline disappeared or looks wrong after I changed a renderer's materials or mesh.
A: The outline materials must stay at the end of the material list and the renderer must keep its baked mesh. The component shows “out of date” with the reason; click Re-Bake.

Q: The outline is not visible in the editor.
A: Un-baked outlines are only generated in Play Mode. Click Bake Outline Assets to see and keep them in the editor.

Q: A baked mesh says it could not be read.
A: Enable Read/Write in the source model's import settings, then bake again. The baked outline mesh itself does not depend on that setting afterwards.
